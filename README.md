## Built with

Plain **HTML, CSS and JavaScript**, with no framework or build step, hosted on **GitHub Pages**. The site is responsive and includes a light/dark theme toggle.

## Run it locally

```bash
git clone https://github.com/ritikpatel-asu/portfolio.git
cd portfolio
# open index.html in your browser, or serve it locally:
python -m http.server 8000
# then visit http://localhost:8000
```
